# Infinite Smile — Entrega SDD

Este paquete contiene la documentación base para reconstruir el feature principal de Infinite Smile mediante Spec-Driven Development.

## Contenido
- `AGENTS.md`: contexto e instrucciones generales para el agente.
- `specs/seguimiento-tratamientos.md`: especificación del feature, reglas de negocio y cinco criterios de aceptación.
- `skills/diseno-marca/SKILL.md`: guía visual de la aplicación.
- `PROMPT_IMPLEMENTACION.md`: prompt para solicitar al agente que implemente el feature siguiendo los documentos.

## Alcance
Prototipo con datos ficticios. No incluye integración real con Google Calendar ni envío de WhatsApp.

## Siguiente paso
1. Revisa y personaliza los documentos.
2. Sube esta carpeta a un repositorio de GitHub o a Google Drive.
3. Abre el proyecto con tu agente de desarrollo.
4. Pídele que lea los tres documentos antes de programar.
5. Comprueba los cinco criterios de aceptación y conserva la evidencia de las pruebas.

**Importante:** este paquete contiene la documentación de SDD, no una aplicación web ya implementada ni un demo publicado.
